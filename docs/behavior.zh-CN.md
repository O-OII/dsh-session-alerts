# 逐会话计数与版本安全的已读确认

[README](../README.zh-CN.md) · [English](behavior.md)

## 任务栏提醒不等于侧栏筛选

统计有未读有效结果或未解决输入请求的主会话并集，每个会话一次；排除子代理 origin/delegation。显示 `1`～`99`，再显示 `99+`，逻辑数字上限999。完成、出错、阻塞、输出超限等有效事件可计入，不取决于哪个应用位于前台。

[铃铛过滤](unread-filter.zh-CN.md)读取的是原生浏览器本地 `completionUnread`，不是成功完成任务列表；重置铃铛不会确认结果或清空任务栏。待处理交互、提醒偏好、后台重跑和状态生命周期不同，都可能让两者不一致。

## 两条有边界的确认路径

两条路径都使用公开官方客户端服务及同一个带认证的逐会话 Host CAS，不做全局清除，也不凭 OS 前台焦点推断所有会话已读。

### 当前原生已读主视图

客户端在全局生命周期内安装一个同步驱动，不依赖 Chat 页脚挂载。必须同时满足：

- `uiSession.current` 指向现有主会话，不是子代理或委派后代。
- 目录为 `ready`、`blank` 明确为 `false`，且 `retainedBy.mainView` 为正安全整数；证明缺失或类型异常时保守拒绝。
- 原生 `uiSession.sessionStatus` 对该会话明确给出 `completionUnread === false`。
- 页面可见、有焦点，连接代际未变。

只查询并确认这个当前会话的终态版本，无需滚回旧回复末尾。来源通知、焦点/可见性变化及重连使在途证据失效；符合条件时仅以一个两秒心跳补足新结果或发布时序竞态，不后台扫描，每个驱动最多一个在途请求。隐藏/卸载视图会取消请求与计时器，并释放订阅。

新页面默认的 false 未读位**不授权批量确认所有目录会话**。原生状态只是当前视图策略的受限输入，不是持久读水位。`pending` 与 `read` 之间出现新结果，Host 版本变化会拒绝旧 CAS；之后若当前视图仍合格，新一轮才可确认那个新版本。

### 精确可见的 Chat 结果页脚

原页脚贡献保留为独立路径：

1. 在官方 `conversation.chat.turnTail` 列表 Slot 挂一像素测量标记，不替换 Chat、不改应用源码。
2. 将当前 `TimelineTurn` 对象的 `turn.turn` 或旧版数字规范化为轮次，再从响应式官方 Chat timeline 读取真实 `turn/end.seq`；Slot 自身 `seq` 和内嵌的旧 end 不是权威证据。
3. 要求当前主会话身份、文档可见/有焦点、IntersectionObserver 交集，并复核标记自身几何与可见性。
4. 只获取该会话的终态版本，核对实际显示的轮次/末序号后提交 `{ sessionId, revision, kind, turn, eventSeq }`。

因此单独显示旧页脚不能确认新结果；如果另一条当前原生已读主视图路径合格，则可不依赖旧页脚确认当前终态。缺少 IntersectionObserver 只禁用页脚路径，不影响已满足接口的当前视图路径。

## 共享的 Host 防线

Host 校验 owner 权限、请求形状、取消、挂载存活、随机挂载 epoch 及当前精确版本，同步 CAS 仅确认匹配的终态。客户端不乐观减数。先 ACK 后新结果，新结果仍待查看；先新结果后旧 ACK，拒绝旧确认。重复/双窗口确认同一版本只清一次；Host 不保存会自行确认未来事件的粘性活动窗口租约。

上述浏览器条件是已读策略证据，不是眼动或理解证明；文档可见性没有反映的 OS 遮挡无法证明。

## 等待、取消与生命周期

- 启用 `notifyOnWaiting` 时，审批/问题保留计数，直到实际回答/决定或所属操作结束。两条路径都不会仅因查看而解决等待交互。
- 同一会话的终态未读与临时等待独立；确认终态后，仍可因待处理请求保留计数。新轮次/等待及其解决本身不抹去旧未读结果。
- 新有效终态替换旧结果，并结束本轮等待。取消不新增提醒，仅结束等待而保留旧未读；历史 `interrupted`/`forked` 不通知。
- 默认抑制活动目标成功的中间回合；目标最终完成和有效失败仍可计入。
- Session-store detach 是对象卸载，不是已读/删除证据：保留终态未读和轮次去重，结束等待，拒绝晚到事件，直到有效新轮次开始。
- 页面刷新、断线、helper 重启保留 Host 内存状态。**Host 重启、插件重载/停用或崩溃不持久化未读**；不从历史日志补发。删除或无法查看的旧会话可能保留计数直至重置插件，不把卸载冒充持久删除 API。

## 原生显示与限制

helper 只绘制 Host 聚合数，前台也保留，不读取 OS 前台焦点。精确完整 exe 匹配的所有可见窗口显示相同数字；清理重验句柄，拓扑/绘制错误重试当前值。不匹配标题、不改应用身份；同一 exe 的不同 Host 实例无法区分，不能启用竞争提供者；不恢复仅托盘隐藏窗口。

原生已读来源不支持时保守拒绝；非活动/隐藏视图不是读取证明。页脚路径要求实际 Chat 数据；两条路径不保证所有后台/多窗口情形下都与原生侧栏本地集合相等。fake 测试验证状态、资格、取消与桥接顺序，不代表真实布局、shell/DPI 或所有 Explorer 行为验收。示意图不冒充原生截图。
